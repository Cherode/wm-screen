# 短钱理财筛 · R1/R2 · ≤30天可赎

银行理财（现金管理/短持有期）公开数据筛选与展示：风险等级 R1/R2、每日可赎或最短持有 ≤30 天、按收益率排序，含收益趋势图（日/周/月切换）。

- 数据源：招商银行APP代销理财列表公开接口（含招银理财/工银理财等理财子公司产品）
- 更新：GitHub Actions 每日 08:10（北京时间）自动抓取并提交数据
- 站点：GitHub Pages（见仓库 About / Settings → Pages）
- 本地运行：`python3 scraper.py && python3 -m http.server 8123`

**免责声明**：数据来自银行公开披露，仅供参考，不构成投资建议。理财非存款，产品有风险。
